# Thailand 2026 Family Trip Website

Static presentation website for the Bangkok + Krabi family trip.

## GitHub Pages deployment

1. Create a **new public GitHub repository** (recommended name: `thailand-2026-trip`).
2. Upload **all files and folders from this package to the repository root**.
3. In GitHub open **Settings → Pages**.
4. Under **Build and deployment → Source**, choose **GitHub Actions**.
5. The included workflow will deploy the site automatically after each push to `main`.

The public URL will look like:

`https://YOUR-USERNAME.github.io/thailand-2026-trip/`

## Important

The website is static. Real destination photos are loaded from their credited internet sources. Several images use a second independent fallback source if the primary source fails.
